Project UAS Backend Pemrograman Aplikasi Web II

PT. Rosalia Indah Transport

RESTful API Pemesanan Tiket Bus Antarkota & Antarprovinsi berbasis Node.js Express, MongoDB Atlas, Autentikasi Stateless JWT, dan Live Fleet Tracking.

Server API Aktif

Status Backend Vercel Serverless

Terkoneksi ke MongoDB Database (Koleksi: Users, Bus, Rute, Jadwal, Pemesanan)

Dokumentasi JSON /api 🗺️ Peta Live Tracking Bus

Daftar Modul & Fitur Unggulan API

🔐 Autentikasi (JWT)

Autentikasi stateless menggunakan JSON Web Token (SUB-CPMK-10).

POST /api/auth/register
POST /api/auth/login
GET /api/auth/me (Bearer Token)

🚌 Armada & Live Location

Armada bus & update lokasi koordinat GPS secara berkala.

GET /api/bus
GET /api/bus/:id/lokasi (Publik)
PUT /api/bus/:id/lokasi (Admin/GPS)
POST /api/bus (Admin)
DELETE /api/bus/:id (Admin)

🛣️ Rute / Trayek

Trayek antarkota/antarprovinsi beserta agen keberangkatan & penurunan.

GET /api/rute
GET /api/rute/:id
POST /api/rute (Admin)
PUT /api/rute/:id (Admin)
DELETE /api/rute/:id (Admin)

📅 Jadwal Keberangkatan

Penjadwalan bus, jam berangkat/tiba, tarif, dan ketersediaan kursi.

GET /api/jadwal
GET /api/jadwal/:id
POST /api/jadwal (Admin)
PUT /api/jadwal/:id (Admin)
DELETE /api/jadwal/:id (Admin)

🎫 Transaksi Pemesanan Pulang-Pergi & Share Live Tracking (Inovasi Fitur)

Mendukung transaksi tiket sekali jalan, pulang-pergi, maupun multi-kota dengan tautan pelacakan publik (ala GrabFood) ke keluarga/teman.

GET /api/pemesanan (Pelanggan/Admin)
GET /api/pemesanan/:id (Pelanggan/Admin)
POST /api/pemesanan (Booking Pulang-Pergi)
PUT /api/pemesanan/:id/status (Lunas/Batal)
GET /api/tracking/:token (Link Publik)
